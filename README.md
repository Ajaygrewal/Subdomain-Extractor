🔍 Subdomain Extractor
Extract all domains & subdomains from any webpage in seconds!
Perfect for bug hunters, security researchers & penetration testers.
---
✨ What It Does
✅ Click extension → "Scan Page" → Get all domains  
✅ Filter by extension (.com, .in, .uk, .org, etc.)  
✅ Search domains by name  
✅ Copy all or individual domains  
✅ Download as CSV, JSON, or TXT  
✅ Works on ANY website
---
🚀 Installation
Chrome Installation
Download & Extract:
Download `subdomain-extractor-CHROME-FIREFOX.zip`
Extract the ZIP file to a folder
Load in Chrome:
Open `chrome://extensions/`
Turn ON "Developer mode" (top right)
Click "Load unpacked"
Select your extracted folder
Done! ✅

---
📖 How to Use
Open any website (GitHub, Twitter, Facebook, etc.)
Click the extension icon 🔍
Click "🚀 SCAN PAGE" button
Wait 1-2 seconds
See all domains extracted!
Use buttons:
Filter by extension
Search by text
Copy all or individual
Download CSV/JSON/TXT

---
🐛 Troubleshooting
No domains found?
Try on different websites
Some sites may have protection
Website must have text content visible
Extension not showing?
Refresh the page
Reload from `chrome://extensions/` or `about:debugging`
Error: "Type error for parameter injection"?
This is a Firefox compatibility issue
Should be fixed in latest version
Try reloading the extension
Can't install?
Make sure Developer mode is ON
Extract ZIP properly (don't use zipped folder directly)
Folder must contain manifest.json file
